# QRKot - Благотворительный фонд поддержки котиков

## Описание проекта

QRKot — приложение для Благотворительного фонда поддержки котиков. Фонд собирает пожертвования на целевые проекты: медицинское обслуживание, обустройство кошачьих колоний, кормление бездомных кошек и другие цели.

### Основные функции:
- **Проекты**: Создание, просмотр и управление целевыми проектами.
- **Пожертвования**: Возможность для пользователей делать пожертвования в фонд.
- **Инвестирование**: Автоматическое распределение пожертвований по открытым проектам.
- **Пользователи**: Регистрация, аутентификация и управление пользователями.
- **Отчеты**: Формирование отчета в Google Sheets о закрытых проектах, отсортированных по скорости сбора средств.

## Установка и запуск

1. **Клонирование репозитория**:
   ```bash
   git clone https://github.com/Dmkdok/QRkot_spreadsheets.git
   cd QRkot_spreadsheets
   ```

2. **Создание виртуального окружения**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/MacOS
   venv\Scripts\activate     # Для Windows
   ```

3. **Установка зависимостей**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройка переменных окружения**:
   - Создайте файл `.env` в корневой директории проекта.
   - Добавьте учетные данные для сервисного аккаунта Google API (см. раздел "Настройка Google API").

5. **Запуск приложения**:
   ```bash
   uvicorn app.main:app --reload
   ```

6. **Документация API**:
   - После запуска приложения, документация будет доступна по адресу: `http://127.0.0.1:8000/docs`.
   - Для просмотра документации в формате ReDoc, загрузите файл `openapi.json` на сайт [ReDoc](https://redocly.github.io/redoc/).

## API Endpoints

### Проекты (Charity Projects)
- **GET /charity_project/**: Получить список всех проектов.
- **POST /charity_project/**: Создать новый проект (только для суперпользователей).
- **DELETE /charity_project/{project_id}**: Удалить проект (только для суперпользователей).
- **PATCH /charity_project/{project_id}**: Обновить проект (только для суперпользователей).

### Пожертвования (Donations)
- **GET /donation/**: Получить список всех пожертвований (только для суперпользователей).
- **POST /donation/**: Сделать пожертвование.
- **GET /donation/my**: Получить список пожертвований текущего пользователя.

### Аутентификация (Auth)
- **POST /auth/jwt/login**: Вход в систему (получение JWT токена).
- **POST /auth/jwt/logout**: Выход из системы.
- **POST /auth/register**: Регистрация нового пользователя.

### Пользователи (Users)
- **GET /users/me**: Получить информацию о текущем пользователе.
- **PATCH /users/me**: Обновить информацию о текущем пользователе.
- **GET /users/{id}**: Получить информацию о пользователе по ID (только для суперпользователей).
- **PATCH /users/{id}**: Обновить информацию о пользователе по ID (только для суперпользователей).

### Google Sheets (Google)
- **GET /google/**: Создать и обновить отчет в Google Sheets с данными о закрытых проектах, отсортированных по скорости сбора средств.

## Инвестирование

После создания нового проекта или пожертвования автоматически запускается процесс инвестирования:
- Пожертвования распределяются по открытым проектам по принципу FIFO (First In, First Out).
- Если сумма пожертвования превышает требуемую сумму проекта, остаток переносится на следующий проект.
- Если в момент создания нового проекта есть нераспределенные пожертвования, они автоматически инвестируются в новый проект.

## Отчеты в Google Sheets

Приложение позволяет формировать отчет о закрытых проектах в Google Sheets. Отчет включает:
- Список закрытых проектов, отсортированных по времени, затраченному на сбор средств (от меньшего к большему).
- Автоматическое создание таблицы на Google Диске сервисного аккаунта.
- Выдача прав доступа вашему личному аккаунту для просмотра и редактирования таблицы.

### Реализация:
- **Метод `get_projects_by_completion_rate`**: Сортирует закрытые проекты по времени сбора средств с использованием `extract` из SQLAlchemy для анализа дат в SQLite.
- **Функция `spreadsheets_create`**: Создает новую таблицу на Google Диске.
- **Функция `set_user_permissions`**: Предоставляет права доступа вашему личному аккаунту.
- **Функция `spreadsheets_update_value`**: Обновляет данные в таблице на основе отсортированных проектов.
- **Роутер `/google`**: Управляет созданием и обновлением отчета.

### Настройка Google API:
1. Создайте сервисный аккаунт в Google Cloud Console.
2. Скачайте JSON-файл с учетными данными.
3. Добавьте в `.env` следующие переменные:
   ```
   GOOGLE_CREDENTIALS=путь_к_вашему_json_файлу
   GOOGLE_EMAIL=ваш_email@gmail.com
   ```
4. Убедитесь, что Google Drive API и Google Sheets API включены в вашем проекте Google Cloud.

## Технические детали

- **База данных**: SQLite (по умолчанию).
- **Аутентификация**: JWT (JSON Web Tokens).
- **Валидация**: Используется Pydantic для валидации данных.
- **Асинхронность**: Приложение построено на FastAPI с использованием асинхронных запросов к базе данных.
- **Интеграция с Google**: Используется библиотека Aiogoogle для работы с Google API.
